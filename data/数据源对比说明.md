# 📊 股价数据源对比说明

## 🎯 可用的数据更新脚本

### 1. ⚡ yfinance（推荐）
**脚本**: `update_prices_yfinance.py`

**优点**：
- ✅ **完全免费**，无 API 限制
- ✅ **速度极快**（约 2 分钟完成 101 只股票）
- ✅ **数据可靠**，来自 Yahoo Finance
- ✅ **无需 API 密钥**
- ✅ **支持实时数据**

**缺点**：
- ⚠️ 偶尔可能有数据延迟
- ⚠️ 依赖 Yahoo Finance 服务稳定性

**使用方法**：
```bash
cd data
python3 update_prices_yfinance.py
```

**配置**：
- 第 9 行：`CUTOFF_DATE` - 截止日期
- 第 10 行：`START_DATE` - 开始日期
- 第 11 行：`END_DATE` - 结束日期

---

### 2. 🔑 Alpha Vantage
**脚本**: `update_prices_after_date.py` 或 `get_daily_price.py`

**优点**：
- ✅ 数据质量高
- ✅ 官方 API，稳定可靠
- ✅ 支持多种数据类型

**缺点**：
- ❌ **免费版限制严格**：5次/分钟，500次/天
- ❌ **速度慢**（约 20 分钟完成 101 只股票）
- ❌ **需要 API 密钥**

**使用方法**：
```bash
cd data
python3 update_prices_after_date.py
```

**配置**：
- 需要在 `.env` 文件中配置 `ALPHAADVANTAGE_API_KEY`
- 第 11 行：`CUTOFF_DATE` - 截止日期
- 第 12 行：`SYMBOLS_TO_UPDATE` - 要更新的股票列表

## 📝 各脚本详细说明

### `update_prices_yfinance.py` ⭐ 推荐
- **功能**: 使用 yfinance 增量更新股价数据
- **特点**: 
  - 自动合并新旧数据
  - 只添加指定日期之后的数据
  - 保持 Alpha Vantage 格式兼容
  - 更新所有 101 只股票（纳斯达克100 + QQQ）
- **耗时**: 约 2 分钟
- **推荐场景**: 日常更新、快速测试

### `update_prices_after_date.py`
- **功能**: 使用 Alpha Vantage 增量更新股价数据
- **特点**:
  - 自动合并新旧数据
  - 只添加指定日期之后的数据
  - 可选择更新部分或全部股票
- **耗时**: 约 20 分钟（全部股票）
- **推荐场景**: 需要高质量数据时

### `update_prices_quick.py`
- **功能**: 使用 Alpha Vantage 快速更新持仓股票
- **特点**:
  - 只更新 TSLA, COST, ASML, QQQ
  - 完全替换旧数据
- **耗时**: 约 1 分钟
- **推荐场景**: 快速验证

### `update_prices_all.py`
- **功能**: 使用 Alpha Vantage 完整更新所有股票
- **特点**:
  - 更新所有 101 只股票
  - 完全替换旧数据
- **耗时**: 约 20 分钟
- **推荐场景**: 首次设置或完全重建数据

### `get_daily_price.py`（原始脚本）
- **功能**: 使用 Alpha Vantage 下载股价数据
- **特点**:
  - 简单直接
  - 无限流控制（容易触发限制）
- **不推荐**: 建议使用上面的改进版本


### Q3: 如何验证数据是否更新成功？
**A**: 检查最新日期：
```bash
python3 -c "
import json
with open('daily_prices_TSLA.json') as f:
    data = json.load(f)
    dates = sorted(data['Time Series (Daily)'].keys())
    print(f'最早: {dates[0]}, 最新: {dates[-1]}, 总天数: {len(dates)}')
"
```

**A**: 是的！所有脚本都输出相同的 Alpha Vantage 格式，完全兼容现有系统。

## 📊 数据质量检查

运行以下命令检查数据完整性：
```bash
python3 -c "
import json
import os

symbols = ['TSLA', 'COST', 'ASML', 'QQQ']
for symbol in symbols:
    filename = f'daily_prices_{symbol}.json'
    if os.path.exists(filename):
        with open(filename) as f:
            data = json.load(f)
            dates = sorted(data['Time Series (Daily)'].keys())
            print(f'{symbol:6s}: {dates[0]} 到 {dates[-1]}, 共 {len(dates)} 天')
    else:
        print(f'{symbol:6s}: 文件不存在')
"
```
